
# Öğrenci Bilgi Sistemi

React.js, Node.js, Express.js ve MySQL kullanılarak geliştirilen öğrenci bilgi sistemi.

## Proje Teknolojileri

- React.js
- Node.js
- Express.js
- MySQL
- JWT
- HTTP Cookie
- Fetch API
- Git ve GitHub

## Proje Yapısı

- frontend: React kullanıcı arayüzü
- backend: Express sunucusu ve API işlemleri

## Geliştirme Aşaması

İlk aşamada kullanıcı girişi, JWT kimlik doğrulaması ve Cookie tabanlı oturum yönetimi geliştirilecektir.
